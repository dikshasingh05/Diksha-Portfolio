# Diksha Singh Portfolio

Static HTML/CSS/JavaScript portfolio. No build step required.

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or simply double-click `index.html`.
3. For the best experience, use the Live Server extension.

## GitHub Pages
Push the complete folder contents to a GitHub repository with `index.html` at the repository root, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
