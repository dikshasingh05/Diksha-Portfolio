Smart Automated Window

GitHub · Dec 2025

An IoT-based automated window system that intelligently controls window opening and closing based on real-time environmental conditions — built as a hands-on embedded systems project.

  • Integrated Arduino, LDR, a rain sensor, an MQ-series gas sensor, DHT22, a servo motor and a 16×2 LCD for real-time monitoring and automated control.
  • Automatic window operation driven by day/night conditions, rain detection and air-quality readings.
  • Live temperature and humidity display on the onboard LCD.
